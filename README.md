# Radar IA Salud

Biblioteca pública y viva de estudios recientes sobre inteligencia artificial aplicada a la salud, ingeniería biomédica y tecnología médica.

## Estructura
- `index.html`: interfaz pública.
- `data/studies.json`: base de estudios separada del diseño.

## Qué contiene cada estudio
- país y bandera;
- institución o grupo;
- muestra y diseño;
- modalidad de datos;
- modelo/arquitectura;
- métricas principales;
- lenguaje, framework y hardware cuando se reportan;
- costos cuando están disponibles;
- limitaciones;
- enlaces al paper y repositorio/código.

La separación entre interfaz y datos permite actualizar la biblioteca diariamente sin rehacer toda la página.
